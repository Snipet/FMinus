To grow the language, read architecture.md, then extending.md, then simd.md. Use building.md and testing.md as
reference. To write programs in it, read programs.md.

Elsewhere:

- [../README.md](../README.md) is the quick reference: the language, using FMinus as a C++ library
  (`include/fminus/FMinus.h`), the commands, the presets.
- [../examples/biquad/README.md](../examples/biquad/README.md) plans the language's growth around a DSP kernel, which
  processes a block of samples in one call.
- [../examples/note/note.fm](../examples/note/note.fm) is a whole program, with a `main`.
- [../examples/](../examples/) shows each feature in use: `waveforms/` (loops, a `switch` on an enumeration, and a
  constant of the top level), `chord/` (`float4` and the vector math library), `unison/` (`poly float`), `comparison/`
  (a `bool main`), `biquad/` (a module filtering a block a call, its cutoff a stream), `delay/` (the heap, and a kernel
  that can't allocate, in plain C and as a module), `saturator/` and `meter/` (`poly float` through a buffer, against
  plain loops: a stateless tanh, and reductions; each a module with a knob, the meter's readings labelled for its host
  by their attributes), `voices/` (modules, in memory a host of the
  public API allocates, their controls knobs), `convolver/` (the FFT: a convolution by overlap-add), `parameters/` (a
  filter's cutoff swept through a knob or a stream, or frozen), `noise/` (white noise from a count of samples, `randf`,
  and a voice's own source, `hash`), `plugin/` (a JUCE plugin whose DSP is an FMinus program: a stream, knobs and a
  frozen sample rate, compiled in `prepareToPlay`, its own CMake project), `wavetable/` (tables from a JSON or an XML
  document), `fetch/` (the same pack fetched from a server its host allows: the web library), `remote/` (a
  synthesiser a browser controls, its requests taken in its nonblocking `process`: the web library's server) and
  `kit/` (a drum kit whose sounds are files in a folder its host grants, loaded off the audio thread and played on it:
  the file interface), and `trigger/` (an envelope a gate triggers, its note-on found by `when`).
